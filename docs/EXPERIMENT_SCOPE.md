# Experiment scope

The manuscript reports experiments on the Charlotte Anomaly Dataset (CHAD). The checked-in `CHAD_Selected_Videos/` directory is the selected 19-video subset used for actor-pair annotation and supporting experiments. Full metadata and official split files are downloaded separately from the official CHAD repository.

The manuscript DOCX is kept outside this public repository and is submitted separately. Raw metadata, the full virtual environment, generated feature arrays, and model checkpoints remain outside the Git source package unless a later release explicitly adds them.
